# Career Training College Member Management System

An internal member management system developed with Laravel and MySQL.

The application allows authorised users to log in and manage member records through CRUD operations.

## Features

- User login
- View member records
- Add new members
- Edit member information
- Delete members
- Form validation
- Database integration

## Technologies Used

- PHP
- Laravel
- MySQL
- Blade
- HTML
- CSS
- JavaScript
- XAMPP
- Visual Studio Code

## Project Purpose

This academic project was developed as part of my Diploma of Information Technology.

The goal was to create an internal system for Career Training College staff to manage member records.
